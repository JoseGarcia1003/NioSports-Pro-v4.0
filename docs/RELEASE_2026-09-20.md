# Entrega del 20 de septiembre de 2026

Esta entrega permite revisar una versión más clara y mejor protegida de NioSports Pro. Sigue siendo una vista previa: aún faltan conexiones y validaciones antes de ofrecerla como producto comercial completo.

## Lo que cambia para el usuario

| Área | Qué se corrigió o incorporó | Para qué sirve |
|---|---|---|
| Pronósticos | Catálogo del día con selección, probabilidad estimada, argumentos, fuente y hora de corte separados | Entender qué dice el modelo y en qué información se apoya |
| Acceso FREE | Una selección Premium fija por fecha cuando hay edición disponible | Recargar o cambiar de filtro no desbloquea otra selección |
| Contenido Premium | El servidor decide qué contenido puede recibir cada cuenta | El bloqueo protege los datos; no depende de esconder texto en la pantalla |
| Presentación | DM Sans, pesos coherentes, cifras alineadas, tarjetas y controles más legibles | Leer y comparar con menos esfuerzo en escritorio y móvil |
| Navegación | Barra y logotipo adaptados al tema claro; entrada «Iniciar sesión» para visitantes | Evitar menús que aparentaban una sesión inexistente |
| Bankroll | Colores específicos para ambos temas, textos auxiliares mayores y controles de 44 px | Corregir títulos y avisos casi invisibles en el tema claro |
| Sesiones | Los stores de picks e historial descartan respuestas antiguas al salir o cambiar de cuenta | Evitar que una petición tardía vuelva a mostrar datos de la sesión anterior |
| NBA | Generación asíncrona corregida, cancelación de solicitudes y validación de entradas | No completar análisis con descansos, lesiones o cuotas inventados |
| Base de datos | Permisos corregidos en tablas antiguas; registro contable con operaciones atómicas | Limitar lecturas y cambios de información personal y proteger los movimientos |

El registro nuevo de bankroll no importa saldos antiguos automáticamente. El historial anterior se conserva y la interfaz lo explica. No se han efectuado pagos, transferencias ni apuestas.

Corrección adicional: el propio panel de bankroll descarta respuestas antiguas al alternar demo/cuenta, cambiar de usuario o salir y volver con el mismo usuario. Limpia borradores entre sesiones, evita envíos simultáneos y conserva la clave de reintento ante un resultado incierto. «Actualizar» mantiene el modo demo. Esto protege el estado de la pantalla; cancelar una petición no deshace una operación que el servidor ya haya confirmado.
